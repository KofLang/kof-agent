# SEM038

```
error: cannot assign to 'state': record is immutable [SEM038]
```

Causa: atribuir campo de `record` (0.4.0 tornou records imutaveis).
Workaround: dados que mudam viram `class` com campos `var` implicitos e
`constructor` explicito — foi o destino de CorpMeta (57_corpus) e
ExecTaskState (71_executor) no port ad8cdca. Records permanecem para
DTOs read-only (PlanNode, RunMetrics, ...).
